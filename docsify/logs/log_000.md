# log_000  

## Context
Before starting this project, I had a personal webpage written in Vue.js and deployed on GitHub Pages. What were my issues with the previous project:  

* I didn't like the way Vue.js routing works.  
* I wanted to use a more popular tech stack.  
* I wanted to keep page development simple by using components and reusable elements.  
* I wanted the ability to use libraries.  
* I wanted many features available out of the box so that I could focus on components and page content.  
* I wanted the final output to be a static website.  

## Decision
Therefore, I decided to:  

* Use React.js, one of the most popular frontend frameworks.
* Use Gatsby.js, one of the most popular Static Site Generator frameworks.

## Result
This project was created, I moved all the components from the previous project. 
Additionally:
* I added photography page with gallery.
* I added script to deploy static website to server running in local network.
* I added Google Lighthouse to have some **metrics** on how the website is performing.

All of the above is included in version `v1.0`.
