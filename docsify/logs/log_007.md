# log_007

## Context

The website was not completely covered by tests:

- tests only parsed the built HTML and CSS files, nothing checked how the pages actually look
- a broken layout, theme or font would pass every test
- each test file kept its own copy of the page list
- the privacy page was not checked by Lighthouse CI

A code review also found leftovers to clean up:

- all 28 font faces were inlined into every page, although only 4 are used
- `prop-types` usage, which React 19 ignores
- unused `chrome-launcher` dependency
- dead background rules in `Page`
- icon names announced twice by screen readers (`alt` repeated the visible label)

## Decision

Add Playwright screenshot tests that compare every page against committed reference screenshots.

Screenshots differ slightly between machines (OS, fonts, browser build), so the tests run in the official Playwright Docker image, both locally and in CI.

## Result

- test suites moved to `tests/suites/`, with the shared page list in `tests/site.js`
- new theme colour token test
- privacy page added to Lighthouse CI
- Playwright screenshots of every page in the light and dark theme, on desktop and mobile (20 references)
- `npm run test` runs all tests, `npm run testOutput` only the build-output suites, `npm run testPlaywright` only the screenshot tests
- `npm run updateScreenshots` rebuilds the site and saves new references after a deliberate visual change
- homepage HTML reduced from 180 KB to 64 KB by importing only the used font weights
- `prop-types`, `chrome-launcher` and dead CSS removed
- icons use an empty `alt`, since their label already names them
- Lighthouse CI thresholds raised from 90 to 95 points
- the CV PDF is still not covered by tests
