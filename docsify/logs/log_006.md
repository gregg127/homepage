# log_006

## Context

The site was missing basic SEO metadata:

- no canonical URLs, Open Graph tags or social preview image
- no `<h1>` on any page
- generic page titles ("About", "Contact")
- raw privacy policy markdown published at `/privacy-policy.md`

## Decision

Add a shared `Seo` component and build all head tags from `siteMetadata` in `gatsby-config.js`.

## Result

- `Seo` component used by every page
- `noindex` on the 404 page
- canonical URLs on all indexable pages
- Open Graph and Twitter Card tags
- 1200×630 social preview image (`og-image.png`)
- JSON-LD `Person` data on the homepage
- exactly one `<h1>` per page
- titles like `About · Grzegorz Gołębiowski`
- privacy policy moved from `static/` to `content/`
- AI crawlers are still blocked in `robots.txt` (a deliberate choice)
