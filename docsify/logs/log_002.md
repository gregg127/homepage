# log_002

## Context

Lighthouse audit of version `v1.11` revealed performance issues, with the `/about` page scoring lowest at 60/100.

The issues for `/about` page are:

- Largest Contentful Paint with value of 13.3s
- First Contentful Paint with value of 5.7s
- Speed Index with value of 5.7s

## Decision

The following optimizations will be implemented:

- Remove developer icons to reduce load time (low value, high performance impact)
- Enable Brotli compression for text assets
- Implement proper caching headers

## Result

After enabling Brotli, Lighthouse performance score on `/about` page increased from 60 to 68 (version v1.14).

After replacing developer icons with static SVG files, the performance score on `/about` increased dramatically from 68 to 91 (version v1.15). SVG files were downloaded from https://www.svgrepo.com.

Caching HTTP headers were added with max-age equal to one year, except for the favicon. Paths to JS files should be hashed, while static files should remain unchanged with current filenames. This allows me to use one-year caching, as any changes will result in new resource paths.

Scores on other pages improved as well with all of the above optimizations.
