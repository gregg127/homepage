## Context
After first Lighthouse audit on version `v1.0` there are few basic things that need to be done:
* Add Brotli (text compression)
* Reduce unused JavaScript - https://www.npmjs.com/package/webpack-bundle-analyzer
* Add `<lang>` to `<html>`
* Serve images in next-gen formats - use gatsby-plugin-image in ImagePanel component
* Fix favicon
* Photography page - use the gatsby-plugin-image component to set appropriate sizes
* Use HTTPS - server configuration
* Use http/2 - server configuration
* Serve static assets with an efficient cache policy - server configuration

## Decision
Fix the application issues with:
* Unused JS
* `<lang>` in `<html>`
* ImagePanel component
* Favicon
* Sizes on photography page

Issues considering server configuration:
* HTTPS
* http/2
* Cache policy
* Brotli

Will not be fixed. Those are based off the environment that static page will be deployed. Deploying on Github Pages should fix all of the above.

## Result

* Unused JS problem has not yet been addressed.
