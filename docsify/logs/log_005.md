# log_005

## Context

Bitnami decided that most of their container images and helm charts will no longer be available for free
as they used to (source: https://www.chkk.io/blog/bitnami-deprecation).
Therefore I need to migrate the bitnami/nginx image that I use to something else.

## Decision

Move to the official nginx Docker image https://hub.docker.com/_/nginx.

This approach uses the well-maintained official image directly from Docker Hub, ensuring long-term availability and support.

## Result

Successfully migrated from bitnami/nginx to the official nginx image:

- Docker container runs as a non-root user
- nginx was compiled with Brotli module ngx_http_brotli_filter_module;
- most of the previous nginx configuration remained the same.

Version v1.23 was released. Lighthouse test showed decrease to 83 points in SEO metric due to:

- Document does not have a meta description
- robots.txt is not valid (Cloudflare related issue)
