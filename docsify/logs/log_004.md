# log_004

## Context
The website needs robots.txt and sitemap.xml files to improve SEO and guide search engine crawlers.

## Decision
Gatsby plugins will be used to generate these files automatically:
- **gatsby-plugin-sitemap**: Generates sitemap.xml with proper page priorities and change frequencies
- **gatsby-plugin-robots-txt**: Creates robots.txt to guide search engine crawlers

This approach ensures the files are generated consistently with each build and stay synchronized with the actual site structure.

## Result
The following files are now automatically generated and available:
- **Sitemap Index**: https://golebiowski.dev/sitemap-index.xml
- **Sitemap**: https://golebiowski.dev/sitemap-0.xml
- **Robots.txt**: http://golebiowski.dev/robots.txt
